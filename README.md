# Repo_Practica_Jet_Compose
Descripción de la aplicación

Esta aplicación es una herramienta interactiva diseñada para demostrar el uso de componentes fundamentales en Jetpack Compose, como Text, Image, Button y OutlinedTextField. Su funcionalidad principal permite al usuario ingresar su nombre en un campo de texto y, al presionar un botón de acción, la interfaz actualiza dinámicamente un mensaje de bienvenida personalizado utilizando la gestión de estado con remember y mutableStateOf. El diseño sigue los principios de Material Design 3, integrando un recurso visual (logotipo) y una disposición organizada mediante el uso de Column y Spacer para garantizar una navegación clara.

Cambios realizados tras la validación

Tras la fase de validación, se realizaron ajustes clave para mejorar la usabilidad y la estética de la interfaz. Se sustituyó el campo de texto básico por un OutlinedTextField para proporcionar un mejor contraste visual y facilitar la identificación del área de entrada. Además, se optimizó el espaciado entre los componentes y se añadió una validación lógica al botón para gestionar campos vacíos, asegurando que el usuario reciba instrucciones claras si olvida ingresar su nombre. Estos cambios permitieron que la aplicación fuera más intuitiva y visualmente equilibrada.
